Welcome to UTP Note Share!

This service allows you to upload and view images, PDFs, Files and Documents related to your course. All materials are provided by fellow students and everyone is welcome to contribute!

Click on the View tab on the left panel to access files already uploaded. You can sort by course, date, file type and more. (Not Implemented!)

Click on the Upload tab to upload files to the service. Supported file types include Images (JPEG, PNG), PDFs, WORD, and txt. Files must not exceed 20 MB. Duplicate files are technically able to be uploaded although this is not recommended, and files that are found to be exact copies will be purged at any time.

Click on the Statistics tab to view statistics about the service. We track the number of transactions, database queries (lookups/ CRUD operations) as well as total data egress volume.
